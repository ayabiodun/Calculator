# Calculator

This project is a working simple calculator for simple operations. I built it to challenge my frontend development skills by using OOP to challenge my understanding and implementation of classes.

This project focuses on simple calculations.

## Built With

* HTML
* CSS
* Typescript

## What I Learned

* How OOP (Object Oriented Programming) is used in projects.
* Strengthened my thinking as a software engineer.
* Gained more confidence recreating real-world website with OOP.

## Future Improvements

* Make the calculator scientific by adding more operations.
* Improve accessibility.

## Running the Project

- `git clone `
- `cd `
- `npm install`
- Then open the `index.html` file in your preferred web browser
